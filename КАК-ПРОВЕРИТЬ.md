# Как всё это запускать (объяснение для «не программиста»)

## Самое главное

**Для самого экспорта не нужно ничего запускать.** Экспортёр — это файл
`Arena.ai - LMSYS Arena Chat Exporter-2.4.0.user.js`, который ставится в Tampermonkey как
обычный userscript. Дальше только кнопки в панели на сайте: `Export everything` (весь список
одним архивом) или `Fetch list` → выбрать → `Export selected JSON + TXT`.

**Инструменты в папках `tools/`, `tests/`, `src/` — это не часть экспортёра.** Они нужны
только чтобы проверять архивы и разрабатывать новые версии. Вы можете вообще их не запускать:
просто загрузите ZIP-ы сюда и попросите «сверь» — я запущу аудит и покажу результат.

---

## Инструменты по одному

| Что | Где | Зачем нужен | Нужен ли вам |
|---|---|---|---|
| **Аудит выгрузки** | `tools/audit_export.py` | Проверяет готовые ZIP: все ли беседы на месте, нет ли потерь и повторов, не стал ли какой-то чат короче предыдущей выгрузки | Полезен. Запускать не обязательно — можно попросить меня |
| Экспортёр (шаблон и сборка) | `src/exporter.template.js`, `tools/build-version.mjs` | Собрать новую версию userscript'а одной командой, чтобы вручную не возиться с вставкой библиотеки | Нет, это для разработки |
| Тесты экспортёра | `tests/exporter.test.mjs` | 53 автоматические проверки: архивы, оба формата, параллельность, повторы, агентные чаты | Нет |
| Замер скорости | `tests/bench-batch.mjs` | Показывает, сколько занимает партия при заданной задержке сети | Нет |
| Реплей партии | `tests/e2e-replay.mjs` | Прогоняет экспорт на сохранённых данных, не заходя на сайт | Нет |
| Локальная проверка всего | `tools/ci.sh` | Запускает тесты и проверки одной командой | Нет |

Итого: **вам нужен только аудит** (и то по желанию).

## Как запустить аудит на своём компьютере (Windows)

1. Установите Python 3: https://www.python.org/downloads/
   В первом окне установщика **обязательно** поставьте галочку **«Add python.exe to PATH»**,
   потом `Install Now`. Больше ничего выбирать не надо.
2. Скачайте архив репозитория: на странице GitHub → зелёная кнопка **Code → Download ZIP** →
   распакуйте, например, в `C:\chat-archive`.
3. Положите свои ZIP-ы в папку внутри `C:\chat-archive` (например, `more latest`), а рядом —
   сохранённый список `arena-chat-list-all-….json`.
4. В Проводнике откройте папку `C:\chat-archive`, щёлкните по пустому месту правой кнопкой с
   зажатым **Shift** → **«Открыть окно PowerShell здесь»** (или «Открыть в терминале»).
5. Вставьте команду (подставьте свои имена папки и файла списка) и нажмите Enter:

   ```
   python tools\audit_export.py --zips "more latest" --list "more latest\arena-chat-list-all-2026-10-03T20-05-43-199Z.json"
   ```

   Если какие-то беседы вы оставили намеренно (например, «кубикус»), добавьте в конец
   `--allow-missing 019c394d "кубикус"` — тогда они будут помечены как `SKIPPED`, и итог
   станет `# result: OK`.

   Чтобы ещё и сравнить с прошлой партией, добавьте:

   ```
   python tools\audit_export.py --zips "more latest" --list "more latest\arena-chat-list-all-2026-10-03T20-05-43-199Z.json" --baseline "latest try_json"
   ```

6. Читайте последние строки отчёта:
   - `# result: OK` — всё в порядке;
   - `# result: PROBLEMS FOUND` — ниже будет список строк `MISSING …` (беседы не найдены) и
     `REGRESSION …` (беседа стала короче, чем в прошлой выгрузке).
   Если что-то непонятно — скопируйте вывод целиком и пришлите мне.

Установка Python нужна один раз, потом шаги 4–6 повторяются за полминуты.

## Если не хочется ничего устанавливать

Ничего и не нужно: загрузите ZIP-ы сюда и напишите «сверь» — я выполню ровно те же проверки
(и, если надо, оформлю отчёт файлом).

## Где что лежит

| Папка | Что внутри |
|---|---|
| `more latest/` | ваша последняя партия (2.4.0, JSON + TXT) и отчёт `AUDIT-2.4.0.md` |
| `latest try_json/`, `latest try/` | предыдущие JSON- и TXT-партии и их отчёты — эталоны для сравнения |
| `tools/`, `tests/`, `src/` | инструменты проверки и сборки (см. таблицу выше) |
| `FEATURES.md` | что умеет каждая версия экспортёра |
| `ARCHIVED-EXPORT.md` | инструкция по экспорту архивных чатов и порядок проверки |
