# Офлайн-реплей реальной партии (проверка 2.4.0 без обращения к arena.ai)

Скрипт `tests/e2e-replay.mjs` прогоняет **настоящий код экспортёра** на **настоящих данных**,
не обращаясь к сайту:

- список бесед берётся из сохранённого `arena-chat-list-all-*.json`;
- ответы `/api/evaluation/{id}` отдаются записями из прошлой JSON-выгрузки (`latest try_json`);
- экспортёр при этом проходит весь свой путь: пагинация списка, параллельная загрузка,
  зачистка токена, сборка JSON и TXT, потоковый ZIP, манифест;
- агентные чаты пропускаются: их выгрузка скребёт HTML `/agent/{id}`, а из сохранённой записи
  собрать обратно Next.js flight-поток нельзя.

```
node tests/e2e-replay.mjs \
  --list "latest try/arena-chat-list-all-2026-10-03T16-39-49-640Z.json" \
  --baseline "latest try_json" \
  --out /tmp/replay --parallel 4

python3 tools/audit_export.py --zips /tmp/replay \
  --list "latest try/arena-chat-list-all-2026-10-03T16-39-49-640Z.json" \
  --baseline "latest try_json"
```

## Результат прогона 2.4.0

| Показатель | Значение |
|---|---|
| Чатов в реплее | 193 (все обычные чаты, которые есть и в списке, и в JSON-эталоне) |
| Пропущено осознанно | 51 агентный чат (см. выше) |
| Успешно / сбоев | 193 / 0 |
| Файлов в ZIP | 387 (193 JSON + 193 TXT + `manifest.json`), 2,91 МБ |
| Манифест | `formats: json+txt`, `archivedCount: 193`, `listScope: all` |
| Аудит против JSON-эталона | **193 общих чата, регрессий 0, изменённых 0** |
| Аудит против сохранённого списка | `missing 51` — это ровно пропущенные агентные чаты, `not in the list 0`, `archive-flag mismatches 0` |
| Время | 2,7 с на 193 чата (сеть в реплее отсутствует — это проверка корректности, а не скорости) |

Вывод: **2.4.0 выдаёт тот же результат, что проверенная 2.3.2** — те же сообщения, те же
вызовы инструментов (`toolCallId`), те же флаги архива; отличается только упаковка и скорость.
Строка «51 chats from the saved list are absent from the export» в отчёте аудитора — ожидаемая:
агентные чаты в этот прогон не подавались.

Дополнительно то же самое проверяется в `tests/exporter.test.mjs` (suite «format parity»):
для одной и той же беседы JSON-записи 2.3.2 и 2.4.0 совпадают (кроме `exportedAt`), а TXT —
**побайтово**.
